# Screenshots

This folder contains screenshots for the Habify app documentation.

## Screenshot Guidelines

### Required Screenshots
- `habits-dashboard.png` - Main habits tracking screen
- `mood-journal.png` - Mood tracking interface
- `hydration-tracker.png` - Water intake tracking
- `settings.png` - App settings screen

### Image Specifications
- **Format**: PNG or JPG
- **Resolution**: 1080x1920 (or similar phone aspect ratio)
- **Quality**: High resolution, clear text
- **Background**: Use actual app screenshots, not mockups

### Naming Convention
- Use descriptive names with hyphens
- Include the main feature in the filename
- Keep names lowercase for consistency

## How to Take Screenshots

1. **Use Android Studio Emulator** or physical device
2. **Take screenshots** of key app screens
3. **Crop if needed** to focus on important content
4. **Save with descriptive names** in this folder
5. **Update README.md** with actual image paths
